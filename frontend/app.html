Load Simulator — autoscaling demo

load · by loadgen (Node)

Generates real CPU load against the facts service. In the k8s lab the autoscaler (HPA) notices within ~15–30s and adds facts pods; here in the compose stack the diagram below simulates that HPA from the measured request rate.

Nothing else to configure — pick a duration and concurrency, press Start Load, and watch the live service graph underneath (or kubectl -n k8slab get hpa -w in the lab).

How long the load runs — HPA samples CPU every ~15s, so 60s+ gives the full demo.

Replica scaling is a simulated HPA driven by the measured request rate — the deployed stack is docker compose; the k8s lab (guide §7) runs the real one.
